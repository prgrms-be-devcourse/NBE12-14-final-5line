# OUTPICK 작업 진행

## 2026-11-27 기존 서비스 데이터 반영
- 공개 검색·필터·상세의 카테고리를 7개 대분류, 9개 세부 종목으로 제한했다. 복합 분류의 기존 TourAPI 장소 25곳은 장소 ID를 유지하며 루지 10곳과 레일바이크 15곳으로 구분했다. 중력 레이싱 확정 장소는 없다.
- 공개 카테고리별 장소 수를 실제 공개 장소 기준으로 계산하고 탐색 화면에 표시했다. 지도와 목록은 기존의 동일 검색 결과를 사용한다.
- 목록 요금 미리보기는 검증된 현재 정상 일반 입장료만 사용하며, 그 외에는 `요금 미확인`으로 표시한다. 상세 화면에는 검증된 요금의 조건과 종목별 확인 정보를 표시한다.
- 스노클링 상세의 안전·수산자원 보호 패널을 기존 페이지에 연결했다. 입수 확인이 없는 장소는 공개 추천에서 제외한다.
- 기존 제외 장소 7곳은 종목 연결이 없음을 확인했다. 기존 장소·회원·리뷰·즐겨찾기 데이터는 삭제하지 않았다.
- 726건 자동 시드는 이후 626건 검수 파일 기준으로 교체되어 비활성화했다. 운영 DB는 변경하지 않았다.
- 가격 28건은 모두 `NEEDS_REVIEW`여서 현재 공개 요금에 표시되지 않는다. 스노클링 입수 허용 확정 장소는 0곳이다. 후보 데이터를 임의로 공개하지 않았다.
- 프런트엔드 테스트 147건 통과, 프로덕션 빌드 통과. 백엔드 전체 테스트도 단독 재실행으로 통과했다.
- 제공된 스노클링 조사 목록 109곳은 기존 검수 후보와 중복됨을 확인했다. 로컬 검수 후보는 총 126건이며 전부 PENDING이다. 운영자 전용 후보 목록 API와 기존 관리자 화면에 `입수 미확인` 표기를 추가했다. 운영자 전용 API 테스트 통과. 공개 검색 및 추천에는 노출하지 않는다.
- 기존 관리자 화면에서 장소 기본정보·공개 상태 수정, 가격·상세 사실 초안 등록 및 근거 검수 기능을 추가했다. 공개 전에는 확인된 공식 출처와 검증일을 요구하며, 스노클링 입수 허용은 공식 출처와 유효기간까지 확인한다.
- 모바일 390px 화면에서 메인과 기존 장소 상세의 가로 넘침이 없고 상세 정보가 정상 표시되는 것을 확인했다. 프런트엔드 전체 147개 테스트와 최종 빌드가 통과했다.
- 남은 데이터 작업: 28개 가격 근거와 126개 스노클링 후보는 모두 검수 대기다. 근거 없는 값이나 입수 가능 여부를 임의로 확정하지 않았다. 운영 DB와 GitHub push/PR/merge는 건드리지 않았다.

- 최종 검증: 백엔드 전체 199개 테스트(35개 스위트) 실패 0, 프런트엔드 147개 테스트 실패 0, 프런트엔드 빌드 성공.

## 2026-11-27 검수 파일로 기준 전환
- `outpick_filtered_review.json`과 `outpick_excluded_facilities.json`을 `data-collection/seed/`에 보관했다. 검수 후보 626건(해수욕장 382건)을 기준으로 삼는다.
- 이전 726건 자동 시드 SQL을 로컬 마이그레이션 경로에서 제거하고 임시 백업으로 옮겼다. 로컬 DB에서 검수 파일과 연결되지 않은 공개 장소 513건을 삭제 없이 비공개 처리했다. 현재 기존 장소 731건 중 공개 상태는 199건이다.
- 해수욕장 후보 382건 중 277건은 좌표가 없고 모든 후보의 `publishReady`가 false다. 검수되지 않은 후보를 공개 장소나 지도 마커로 임의 승격하지 않았다.
- 추가 API 호출 없이 검수 JSON과 `raw_api_data.json`으로 일치한 신규 장소 167건을 로컬 `Place` 초안에 추가하고 기존 21건 등을 후보와 연결했다. 새 장소에 출처와 활동 분류를 연결했고, 157건에 출처가 있는 대표 사진을 저장했다. 현재 전체 Place 898건, 공개 199건, 초안 167건이다. 검수 후보 626건 중 400건이 기존 또는 신규 Place ID와 연결됐다. 별도 스노클링 추가 후보 88건도 여전히 검수 대기다.
- 626건 구성은 `summary.json`의 카테고리별 후보 수와 일치한다. `raw_api_data.json`을 추가 API 호출 없이 재사용해 아이스링크 4곳을 포함했다. 동일 Java Import 재실행 결과 신규 생성 0건으로 중복이 생기지 않았다.

## 2026-11-27 이전 726건 시드 실제 삭제
- `R__local_place_seed.sql`은 Flyway 이력 호환용 no-op으로 바꾸고 적용 성공을 확인했다. 726건 시드 전용 Place 515건은 검수 후보와 겹치지 않고 후기·즐겨찾기·별칭 연결이 0건임을 확인한 뒤 로컬 DB에서 삭제했다. 726건 CSV·생성 스크립트는 프로젝트에서 제거해 임시 백업으로 옮겼다.
- 검수 후보에만 있던 314건을 실제 비공개 Place 초안으로 추가했다. 검수 후보 테이블 714건(기본 검수 파일 626건 + 후속 스노클링 후보 88건) 모두 Place ID가 연결돼 있다. 중복 후보가 같은 Place를 가리키는 경우가 있어 고유 Place는 692건이며, 기존 테스트·비시드 장소 5건을 포함한 로컬 전체 Place는 697건이다. 공개 199건, 초안 481건. 미확인 좌표·입수 여부는 채우지 않았다.

## 메인 페이지 개편
- `/`에 사진 기반 히어로·검색·7개 카테고리·계절별 활동·푸터를 추가하고 기존 탐색은 `/explore/`로 분리했다. 기존 루트 쿼리 링크는 탐색을 유지한다.
- 실제 API의 카테고리 수와 사진을 사용한다. 추천·비교·테마 기능은 미구현이므로 노출하지 않는다. DB 변경 없음.
- 프론트엔드 빌드 성공. 기존 탐색 테스트의 헤더 경로를 새 `/explore/` 경로로 수정했다.

## 공통 데이터 Flyway 공유
- 신규 V36에서 검수 파일 626건과 후속 스노클링 후보 88건의 실제 반영 결과를 전달한다. 후보 714건이 고유 Place 692곳에 연결된다.
- 계정·세션·리뷰·즐겨찾기·비밀키는 포함하지 않는다. 기존 Place는 출처 ID 또는 동일 검수 근거로 재사용하고, 각 팀원 DB에서 새 ID를 생성한다.
- 목록·상세·카테고리 집계의 입수 허용 테이블 필터를 제거했다. 상세 안전정보의 입수 상태와 추천 여부는 계속 별도로 표시한다.
- 빈 로컬 DB 전체 Flyway 적용 성공. 기존 데이터의 상세 근거 키 충돌을 중복 방지 조건으로 보완한다. 팀원 적용 방법은 `data-collection/SHARING.md`에 기록했다.

## 기존 조사 자료 상세 화면 연결
- 메인 페이지와 DB 데이터는 수정하지 않았다. 기존 상세 페이지를 사진 왼쪽·소개 오른쪽과 정보 메뉴·정보 카드로 정리하고, 운영 상태 UNVERIFIED를 한국어로 표시했다.
- DB 저장: 기존 상세 근거 37건, 구조화 가격 28건, 수산자원 규정 54건을 유지한다. 후보 JSON의 officialPatches·apiPriceEvidence·intro·details를 읽어 현재 유효성이 검증되지 않은 자료를 검수 대기로 제공한다. 할인·쿠폰·제휴 문구는 제외한다.
- API: 공개 장소에 한해 `/api/v1/places/{placeId}/research-details`에서 요금·대여·운영·개폐장·이용 조건의 출처/조사일/검수 상태를 반환한다. VERIFIED 요금과 규정은 기존 API와 필터를 유지한다. 공통 자료는 이미 V36에 포함돼 팀원 환경에서도 재현 가능하다.
- 화면 확인: 구미 낙동강 스노우파크 운영·개폐장·요금 자료 6개, 장호항 해양레저체험장 대여료·운영 시즌·준비물·예약·문의전화 자료가 실제 상세 화면에 표시됐다. 입수 미확인 안내와 금어기 검수 대기 자료, 방문일 선택·119·GPS 기능도 표시됨을 확인했다. GPS 권한은 자동 요청하지 않았다.
- 검증: Java 컴파일 성공, 프런트엔드 빌드 성공, 프런트엔드 테스트 147개 통과. 브라우저 축소 화면의 가로 넘침 없음(실제 브라우저 최소 너비 487px). 관할 해경 연락처와 현재 시즌 가격의 공식 검증이 없는 항목은 미확인/검수 대기 유지. GitHub 업로드 없음.

## 상세 안내 통합 및 UI 정리
- Lucian UX/UI Prompt의 경로 탐색·상세정보 펼치기·로딩 상태 패턴을 공통 상세 페이지에 반영했다. 모든 장소에 동일한 정보 카드·여백·상단 소개 축약·정보 메뉴를 적용한다. 메인은 변경하지 않았다.
- 하단 운영정보 카드를 제거하고 상단 요금·운영 안내에 문의전화·수집일·검수일·대조일을 통합했다. 같은 내용의 운영시간·휴무일은 HTML·공백 차이를 정규화해 중복 표시하지 않는다.
- 해수욕장의 빈 요금 패널과 요금 미확인 행은 숨기되 실제 주차·편의시설 요금은 유지한다. 월정리 상세 화면에서 운영정보 카드 제거, 조사자료 4건과 누락 정보 3건의 통합, 빈 요금 경고 미표시를 확인했다.
- 최종 빌드 성공. 전체 테스트는 동시 실행 부하를 줄여 149개 통과했으며 해수욕장 빈 요금 숨김·실제 요금 유지 테스트를 추가했다.
