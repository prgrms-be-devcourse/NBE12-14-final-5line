# 공통 접근 권한 및 개인정보 보호 현황

기능정의서 11번의 현재 구현 범위와 배포 확인 항목을 구분한다.

## 인증과 권한

- 공개 장소·후기 조회는 비회원도 가능하다. 회원 전용 요청은 Spring Security 세션 인증을 요구하고, 변경 요청은 CSRF 토큰을 요구한다.
- 운영자 장소·후기 신고 처리에서는 서버가 현재 회원의 역할을 다시 조회한다. 관심 장소와 후기 수정·삭제는 서버가 인증된 회원 ID와 소유자를 대조한다.
- 로그인 실패는 정규화한 이메일과 접속 주소 조합별로 15분간 5회까지 허용한다. 이후 같은 조합의 로그인은 429로 거절하고, 15분이 지나거나 성공하면 실패 횟수를 초기화한다. 키는 SHA-256 해시로 메모리에 보관하며 원본 이메일을 저장하지 않는다.
- 로그인 제한은 현재 **단일 백엔드 인스턴스의 메모리**에서 동작한다. 여러 인스턴스로 확장하면 공유 저장소 기반 제한으로 바꿔야 한다. 제보 API는 아직 구현되지 않아 제보 요청 제한도 미적용이다.

## 쿠키와 로그

- 세션 쿠키는 `HttpOnly`, `SameSite=Lax`로 설정한다. HTTPS Compose 구성을 사용할 때는 `Secure`를 켠다. HTTP로 실행하는 로컬 환경에서는 `Secure`를 강제하지 않는다.
- 요청 ID만 MDC에 저장한다. 500 오류는 예외 유형과 발생 위치만 기록하며 예외 메시지·요청 본문·비밀번호·세션 값을 로그에 기록하지 않는다. Nginx 접속 로그는 쿼리 문자열을 제외한 경로만 기록해 비밀번호 재설정 링크의 토큰이 남지 않도록 한다. 운영 로그 수집 설정은 배포 시 별도로 점검해야 한다.
- 지도 JavaScript 키의 허용 도메인은 카카오디벨로퍼스 설정에서 관리한다. 2026-11-19에 앱 설정 화면을 읽기 전용으로 확인했을 때, 현재 JavaScript 키에는 SDK 도메인이 등록되어 있지 않았다. 도메인 등록은 앱 소유자의 별도 설정 작업이다.

## 남은 작업

- 개인정보처리방침과 이용 안내는 실제 운영 주체·연락처·제보 데이터 보존 방식이 확정된 후 게시한다. 운영 주체와 개인정보 문의처는 현재 팀에서 미정이라고 확인했다. 미확정 내용을 법적 고지로 임의 작성하지 않는다.
- 장소 정보 오류 제보 기능이 추가되면 제보 소유권과 요청 제한을 함께 적용한다.
