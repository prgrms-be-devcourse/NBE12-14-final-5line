# Lucian UX/UI Prompt

React adaptations of the interaction patterns: #008, #012, #041, #048, #061, #242, #262, #288, #305, #336, #381, #416, #424, #435, #436, #439, #440, #441.
Source: https://lucianlabs.dev/en/uxui-prompt/
Repository: https://github.com/Seokwoooo/lucian-uxui-prompt

The original standalone demos are adapted to OUTPICK components, brand tokens, existing API data and Kakao Maps. Demo facility, map, rating and price data are not included.
