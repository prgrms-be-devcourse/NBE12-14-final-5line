# 공통 장소 데이터 적용

최신 브랜치를 받은 뒤 기존 방식으로 백엔드를 실행하면 Flyway V20~V36이 적용됩니다. V36에는 `outpick_filtered_review.json` 626건과 후속 스노클링 후보 88건의 반영 결과가 포함됩니다. 후보 중 동일 출처 장소를 공유하는 경우가 있어 실제 Place는 692곳입니다.

- 별도 API 키나 TourAPI 호출 없이 적용됩니다.
- Place 기본정보, 종목·시즌, 사진 출처, 운영정보, 가격·상세 근거 및 검수 상태를 전달합니다.
- 기존 Place는 출처 유형·원본 ID로 찾습니다. 로컬 DB의 숫자 ID를 팀원 DB에 강제 삽입하지 않습니다.
- 회원·리뷰·즐겨찾기는 포함하지 않습니다. 기존 Place는 유지하며 기존 상세 값을 덮어쓰지 않습니다.
- 공개 장소를 검색할 때 입수 허용 확인 테이블로 제외하지 않습니다. 입수 상태와 추천 가능 여부는 상세 안전정보에서 별도로 제공합니다.
- 좌표가 없는 장소는 지도에 마커를 만들지 않습니다. 미확인 요금·입수 정보는 임의 확정하지 않습니다.
- 폐기된 726건 로컬 시드는 실행되지 않습니다. `db/local/R__local_place_seed.sql`은 기존 이력 호환용 no-op입니다.

운영 DB 적용 전에 백업과 배포 담당자의 검토가 필요합니다. 이번 작업은 로컬 DB에서 검증했습니다.
